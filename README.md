# ascii-rts-castle

Многопользовательская RTS-игра с ASCII-графикой и архитектурой клиент–сервер, вдохновлённая картой "Castle Fight" из Warcraft 3.

## Описание проекта

**ascii-rts-castle** — это стратегия в реальном времени, где игроки строят здания, которые автоматически спавнят юнитов, сражающихся на линиях. Цель — уничтожить базу противника, защищая свою.

### Основные возможности

- **Клиент-серверная архитектура**: LAN-игра для 2–4 игроков
- **Разнообразные юниты с уникальными характеристиками**: 
  - **Infantry (I)**: высокий HP (160), средний урон (12), ближний бой, быстрая атака
  - **Archer (A)**: средний HP (80), дальний бой (3.5), средний урон (10)
  - **Mage (M)**: низкий HP (70), высокий урон (18), дальний бой, медленная атака
  - **Siege (S)**: очень высокий HP (240), средний урон (20), но x2 урон по базам, медленный
- **Тактический бой**: юниты останавливаются для атаки, базы атакуют юнитов как турели
- **Цветовая индикация HP**: зелёный (66%+), жёлтый (33-66%), красный (<33%)
- **Разнообразные здания**: казармы, стрельбища, башни магов, мастерские, золотые шахты
- **Система апгрейдов с временем исследования**: апгрейды требуют время для завершения
- **Кривые линии**: три изогнутые дороги между базами для визуального интереса
- **ASCII-рендер**: терминальный и GUI-интерфейс (120xN) с HUD, логом событий и панелью действий
- **Кастомные карты**: поддержка конфигов карт через JSON-файлы

## Требования

- **Python 3.11+**
- Зависимости для разработки (устанавливаются автоматически)

## Установка

### Windows (быстрый старт)

Для Windows доступны готовые скрипты. См. [QUICKSTART.md](QUICKSTART.md) для подробных инструкций.

**Быстрый запуск:**
- Сервер: `setup_and_run_server.bat`
- Клиент: `setup_and_run_client.bat --mode local` (для тестирования) или `setup_and_run_client.bat` (для сетевой игры)

### Ручная установка

1. Клонируйте репозиторий:

   ```bash
   git clone <repository-url>
   cd "Castle ASCII"
   ```

2. Установите проект в режиме разработки:

   ```bash
   pip install -e ".[dev]"
   ```

   Это установит проект и все зависимости для разработки (`pytest`, `mypy`, `black`, `ruff`).

## Запуск сервера

### Windows (рекомендуется)

Используйте готовый скрипт:

```cmd
setup_and_run_server.bat
```

Или с параметрами:

```cmd
run_server.bat --port 9000 --required-players 3
```

Подробнее см. [QUICKSTART.md](QUICKSTART.md).

### Ручной запуск (Linux/Mac/Windows)

```bash
python -m ascii_rts_castle.server.main \
  --host 0.0.0.0 \
  --port 8765 \
  --required-players 2 \
  --log-level INFO
```

### Запуск с кастомным конфигом карты

```bash
python -m ascii_rts_castle.server.main \
  --host 0.0.0.0 \
  --port 8765 \
  --required-players 2 \
  --config-file configs/maps/default.json \
  --log-level INFO
```

### Параметры сервера

- `--host` — адрес для прослушивания (по умолчанию: `0.0.0.0`)
- `--port` — порт для прослушивания (по умолчанию: `8765`)
- `--max-players` — максимальное количество игроков (по умолчанию: `4`)
- `--required-players` — минимальное количество игроков для старта игры (по умолчанию: `2`)
- `--config-file` — путь к JSON-файлу конфигурации карты (опционально, по умолчанию используется встроенный конфиг)
- `--log-level` — уровень логирования: `DEBUG`, `INFO`, `WARNING`, `ERROR` (по умолчанию: `INFO`)

## Запуск клиента

### Быстрый запуск (Python-скрипты)

**GUI режим (окно):**
```bash
# Локальный режим
python run_client_gui.py --mode local

# Сетевой режим
python run_client_gui.py --mode network --host 127.0.0.1 --port 8765 --name Player1
```

**Терминальный режим:**
```bash
# Локальный режим
python run_client_terminal.py --mode local

# Сетевой режим
python run_client_terminal.py --mode network --host 127.0.0.1 --port 8765 --name Player1
```

### Windows (альтернатива)

Используйте готовые .bat скрипты:

**Локальный режим (для тестирования):**
```cmd
setup_and_run_client.bat --mode local
```

**Сетевой режим:**
```cmd
setup_and_run_client.bat --mode network --name Player1
```

Подробнее см. [QUICKSTART.md](QUICKSTART.md).

### Ручной запуск (Linux/Mac/Windows)

**Локальный режим (offline-демо):**

Для тестирования игры без сети:

```bash
python -m ascii_rts_castle.client.main --mode local
```

В локальном режиме игра запускается с двумя AI-игроками, и вы можете управлять одним из них.

**Сетевой режим:**

Для подключения к серверу:

```bash
# Терминальный режим
python -m ascii_rts_castle.client.main \
  --mode network \
  --host 127.0.0.1 \
  --port 8765 \
  --name Player1

# GUI режим (графическое окно)
python -m ascii_rts_castle.client.main \
  --mode network \
  --ui window \
  --host 127.0.0.1 \
  --port 8765 \
  --name Player1
```

**Важно**: Сначала запустите сервер, затем подключите 2+ клиентов в сетевом режиме. Игра начнётся, когда все подключённые игроки отправят сигнал готовности.

### Параметры клиента

- `--mode` — режим работы: `local` (локальная демка) или `network` (сетевой клиент)
- `--ui` — режим интерфейса: `terminal` (терминал, по умолчанию) или `window` (графическое окно через pygame)
- `--fps` — целевой FPS для рендеринга (по умолчанию: `60`)
- `--host` — адрес сервера (по умолчанию: `127.0.0.1`)
- `--port` — порт сервера (по умолчанию: `8765`)
- `--name` — имя игрока для сетевого режима (по умолчанию: `Player`)
- `--ai` — включить AI противника в локальном режиме (Player 2 управляется AI)

**Примечание:** Для GUI режима (`--ui window`) требуется установка pygame:
```bash
pip install -e ".[gui]"
```

### Управление в игре

**Выбор линии:**
- `Up` / `Down` — переключение между линиями (1/3, 2/3, 3/3)

**Постройка зданий:**
- `1`, `2`, `3`, `4` — построить здание из панели действий (или клик мышью по панели)

**Исследование апгрейдов:**
- `Q`, `W`, `E`, `R` — исследовать апгрейд из панели действий (или клик мышью по панели)

**Другие действия:**
- `H` — показать/скрыть экран подсказки
- `ESC` или `q` — выход из игры

**Панель действий** отображается внизу экрана и показывает доступные здания и апгрейды с их горячими клавишами.

### Особенности геймплея

- **Центральная боевая зона**: три линии пересекаются в центре карты (40-60% длины линии). В этой зоне юниты с **разных линий** могут сражаться друг с другом, создавая динамичные бои
- **Юниты останавливаются для атаки**: при достижении врага в радиусе атаки юнит останавливается и атакует
- **Базы атакуют юнитов**: базы действуют как турели, обстреливая вражеских юнитов в радиусе 4.5
- **Цветовая индикация HP**: в GUI-режиме цвет юнита показывает его здоровье (зелёный/жёлтый/красный)
- **Исследования занимают время**: апгрейды не применяются мгновенно, требуется время исследования (отображается в панели действий как `R:3.2s`)
- **Разные символы зданий**: B (Barracks), R (Range), T (Tower), W (Workshop), G (Gold Mine)
- **Большое окно**: 160×N для лучшей читаемости и визуализации

### Режим с AI противником

В локальном режиме можно включить AI для Player 2 с помощью флага `--ai`:

```bash
# GUI режим с AI
python -m ascii_rts_castle.client.main --mode local --ui window --ai

# Терминальный режим с AI
python -m ascii_rts_castle.client.main --mode local --ai
```

AI будет автоматически строить здания и исследовать апгрейды примерно раз в секунду, создавая интересный противник для тренировки.

## Управление в игре (команды)

Во время игры вы можете вводить команды в терминале:

### Строительство зданий

```
b <lane_id> <building_type_id>
build <lane_id> <building_type_id>
```

**Примеры:**
- `b 1 barracks` — построить казармы на линии 1
- `b 1 gold_mine` — построить золотую шахту на линии 1
- `b 1 archery_range` — построить стрельбище на линии 1
- `b 1 mage_tower` — построить башню магов на линии 1
- `b 1 siege_workshop` — построить мастерскую на линии 1

### Исследование апгрейдов

```
r <upgrade_id>
research <upgrade_id>
```

**Примеры:**
- `r income_1` — исследовать улучшение добычи (+2 золота/сек)
- `r infantry_attack_1` — улучшить оружие пехоты (+20% урон)
- `r infantry_hp_1` — улучшить броню пехоты (+20% HP)
- `r barracks_training_1` — улучшить обучение в казармах (-20% интервал спавна)

### Апгрейд зданий

```
u <building_id>
upgrade <building_id>
```

Повышает уровень конкретного здания (увеличивает его эффективность).

### Другие команды

- `q`, `quit`, `exit` — выход из игры
- `h`, `help` — показать подсказку по командам

## Конфиги карт

Игра поддерживает кастомные конфигурации карт через JSON-файлы. Это позволяет изменять параметры игры: количество и длину линий, характеристики юнитов, зданий и апгрейдов.

### Структура конфига

Конфигурационные файлы находятся в каталоге `configs/maps/`. Пример: `configs/maps/default.json`.

Структура JSON-файла:

```json
{
  "lanes": [
    { "id": 1, "length": 50.0 }
  ],
  "base_hp": 1000.0,
  "starting_gold": 100,
  "starting_income_per_sec": 3.0,
  "unit_templates": { ... },
  "building_templates": { ... },
  "upgrade_templates": { ... }
}
```

### Поля конфига

- **`lanes`** — список линий (каждая линия имеет `id` и `length`)
- **`base_hp`** — начальное HP баз команд
- **`starting_gold`** — стартовое золото каждого игрока
- **`starting_income_per_sec`** — базовый доход золота в секунду
- **`unit_templates`** — шаблоны юнитов (характеристики: HP, урон, скорость и т.д.)
- **`building_templates`** — шаблоны зданий (стоимость, спавн юнитов, бонусы дохода)
- **`upgrade_templates`** — шаблоны апгрейдов (стоимость, эффекты)

### Использование кастомного конфига

При запуске сервера укажите путь к JSON-файлу:

```bash
python -m ascii_rts_castle.server.main \
  --config-file configs/maps/default.json
```

Если `--config-file` не указан, используется встроенный конфиг по умолчанию.

### Создание своей карты

1. Скопируйте `configs/maps/default.json` как основу
2. Измените параметры по своему усмотрению:
   - Добавьте больше линий: `"lanes": [{"id": 1, "length": 50.0}, {"id": 2, "length": 60.0}]`
   - Измените баланс: урон, HP, скорости юнитов
   - Настройте экономику: стартовое золото, доходы
3. Сохраните файл и запустите сервер с `--config-file`
